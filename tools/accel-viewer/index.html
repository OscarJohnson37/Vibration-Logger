Spectrum (FFT)

Hover over the spectrum to read frequency and amplitude.

Each point is the vibration amplitude (in g) at that frequency, from an FFT of the latest samples with a Hann window. Bigger FFT size = finer frequency resolution but slower to react. Highest frequency shown is half the sample rate.

SD card test

Writes a 64 KB test file, reads it back and compares every byte, then reads the start of the newest recording to check it's a valid DLOG file. Safe while recording.
